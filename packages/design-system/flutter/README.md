# Flutter tokens

Dart mirrors of the web tokens live in `apps/mobile/lib/core/theme/`:
- `app_colors.dart` — colour constants
- `app_spacing.dart` — spacing scale
- `app_radius.dart` — border radius
- `app_text_styles.dart` — typography
- `app_theme.dart` — ThemeData composition

Update these files when the token values in `../tokens.css` change.
