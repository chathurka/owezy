## Summary

After profile setup, new users see a short onboarding path to create a group or join one with an invite code, then land in the group workspace / home. Non-essential steps can be skipped. Must not require Premium. Parent epic: [#108](https://github.com/chathurka/owezy/issues/108).

## Functional Requirements

- Authenticated users can create a group with a name (client-generated UUID).
- Authenticated users can join a group via invite code.
- Onboarding screen presents Create / Join / Skip.
- Skip goes to home without blocking the core journey.
- After create/join success, navigate to home (full Group Workspace UI deferred to expense epic; home is sufficient MVP landing).
- Soft deletes on groups and memberships.

## Acceptance Criteria

- POST create group → 201 with group + membership for creator; invite code generated.
- POST join with valid code → 200 membership; invalid → 404 `GROUP_NOT_FOUND`.
- Duplicate join → 200 idempotent (already member).
- Clients show onboarding after profile setup when user has zero groups; Skip allowed.
- No Premium gate.

## Technical Notes

- Tables: `groups` (id uuid PK client, name, invite_code unique, created_by, timestamps, deleted_at), `group_members` (id uuid client, group_id, user_id, role owner|member, timestamps, deleted_at). Unique (group_id, user_id) among active.
- OpenAPI: `POST /v1/groups`, `POST /v1/groups/join`, `GET /v1/groups`.
- Design: adapted from `resources/owezy-web/pages/Groups.dc.html` / SignUp success “Create your first group”; mobile `Groups.dc.html` + Welcome CTA patterns. No dedicated join mock.
