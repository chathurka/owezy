## Summary

Authenticated invitees accept a valid invitation token once and become group members. Invalid, expired, revoked, and reused tokens are rejected. Membership appears for other members after sync via list/overview.

## Functional Requirements

- `POST /v1/invitations/accept` with `{ token }` adds caller as `member` if invitation pending and unexpired.
- Already a member → idempotent success (return group).
- Mark invitation `accepted` after first successful accept.
- Reject expired/revoked/missing tokens with stable codes.
- Existing join-by-code remains.

## Acceptance Criteria

- Valid token → membership + invitation accepted.
- Reuse → `409` `INVITATION_ALREADY_USED` (or not pending).
- Expired/revoked/invalid → `404` `INVITATION_NOT_FOUND` or `409` as appropriate.
- Clients: accept page/form with token field; navigate to group overview.
