## Summary

Users choose a preferred app language. The selection persists on the user profile and clients apply supported locales with English fallback for missing strings. Parent epic: [#108](https://github.com/chathurka/owezy/issues/108).

## Functional Requirements

- Persist `preferredLocale` on the user (`BCP-47` short tags).
- Supported locales for MVP: `en`, `si` (Sinhala). Fallback: `en` for untranslated keys.
- Users update locale via `PATCH /v1/users/me`.
- Clients apply locale immediately after save (and on cold start from profile / stored preference).
- Language picker available on profile setup; full settings polish in E02-S05.
