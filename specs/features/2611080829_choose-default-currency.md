## Summary

Users choose a supported default currency so amounts display in a familiar unit. Changing the preference updates future display defaults only — it never rewrites historical expense or settlement amounts. Parent epic: [#108](https://github.com/chathurka/owezy/issues/108). Builds on `defaultCurrency` already stored at registration and E02-S01 `PATCH /v1/users/me`.

## Functional Requirements

- Authenticated users can set `defaultCurrency` via `PATCH /v1/users/me`.
- Allowed codes: `USD`, `EUR`, `GBP`, `LKR`, `INR` (ISO 4217 subset already used at register).
- Clients display the currency code unambiguously (e.g. `USD`) alongside formatted amounts when amounts exist.
- Changing default currency does not mutate past expenses, splits, or settlements (none rewritten; preference is display/default only).
- Profile setup / onboarding and later settings can present the selector (settings polish in E02-S05).
