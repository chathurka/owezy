## Summary

Members see only groups they belong to, with useful empty states. Group overview shows key metadata (name, role, member count) and an empty activity/balance placeholder until the expense engine ships. Extends E03-S01 list UI with detail/overview screens.

## Functional Requirements

- `GET /v1/groups` returns only active memberships for the caller.
- `GET /v1/groups/:id` returns overview for members only; non-members get 404.
- Overview includes name, inviteCode (for owners/members as today), role, memberCount, and empty activity flag.
- User-web and mobile show list empty state and overview empty activity state.
- Soft-deleted groups are excluded.

## Acceptance Criteria

- Non-member `GET /v1/groups/:id` → `404` `GROUP_NOT_FOUND`.
- Member receives overview with `memberCount >= 1`.
- List never includes groups without active membership.
- Clients show empty copy when no groups / no activity.
- No fabricated balance amounts in API or fixtures.

## Technical Notes
