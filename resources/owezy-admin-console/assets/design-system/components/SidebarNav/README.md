# Sidebar nav
The admin console navigation: 248px `surface` column, grouped by uppercase `overline` labels, 40px items with an 18px outline icon.

- Active: `primary-soft` fill, `primary-text` 700 — no left-edge bars.
- Counts that need attention (open reports, failed batches) use a `danger-soft` pill.
- Collapses to a 72px icon rail under 960px.
