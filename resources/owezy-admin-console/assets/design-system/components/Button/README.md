# Button
Four buttons, 40px high: primary for the one main action on a screen, secondary for supporting actions, ghost for neutral/toolbar, danger for destructive admin actions (suspend, ban, refund).

- Primary: `primary` fill, `on-primary` label, `shadow-button`.
- Secondary: `primary-soft` fill, `primary-text` label.
- Ghost: `surface` + `border-strong`.
- Danger: `danger-soft` + `danger`. Always confirm in a dialog.
- Focus: `primary` border + 4px `primary-soft` ring.
- Classes: `.ow-btn`, `.ow-btn-primary`, `.ow-btn-secondary`, `.ow-btn-danger`.
