# Status badge
A 22px pill with a leading dot that names a state in one word; colour is never the only signal.

| Variant | Class | States |
|---|---|---|
| ok | `.ow-badge.ok` | Active, Healthy, Resolved, Settled, Paid |
| warn | `.ow-badge.warn` | Pending, Degraded, Past due, Retrying |
| bad | `.ow-badge.bad` | Failed, Suspended, Banned, Escalated |
| info | `.ow-badge.info` | In review, Trial, Syncing |
| brand | `.ow-badge.brand` | Premium, Admin |
| neutral | `.ow-badge` | Free, Draft, Inactive |
