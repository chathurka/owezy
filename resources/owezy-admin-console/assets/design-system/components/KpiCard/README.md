# KPI card
A metric at a glance: uppercase label, a `kpi` value, a delta pill and a comparison caption, optionally a sparkline in `chart-1`.

- Card: `surface`, 1px `border`, `radius-lg`, padding 20.
- Delta up: `owed-soft`/`owed` with ▲; down: `danger-soft`/`danger` with ▼. For metrics where down is good (failures), invert the colour, keep the arrow.
- Four per row on desktop, two on tablet, one on phone.
