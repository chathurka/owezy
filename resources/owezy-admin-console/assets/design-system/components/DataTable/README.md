# Data table
Admin lists live in a table card: header band in `surface-sunken`, uppercase `overline` headers, 56px rows with `divider` lines, numbers right-aligned in tabular figures.

- First column: avatar or category tile + name (`body-strong`) + meta (`caption`).
- Last column: 32px ghost "more" icon button with an `aria-label`.
- Above: the filter bar (search, selects, Export, primary action). Below: "1–10 of N" + pager.
- On narrow screens the card scrolls horizontally; never wrap cells.
