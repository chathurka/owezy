What's in this folder
pages/ — every screen as standalone HTML, with owezy-runtime.js powering the interactions (filters, sorting, toggles, forms).
screenshots/ — full-page PNG of every screen.
design-tokens/ — tokens.json and tokens.css (light + dark CSS variables, type classes).
source/ — the original design-canvas files, for re-importing or editing.
Fonts load from Google Fonts; offline, pages fall back to the system font.
