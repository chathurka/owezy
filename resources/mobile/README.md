# resources/mobile

Place Flutter design mocks and design asset documentation here before running `/spec-build` for a mobile UI feature.

## Expected contents

| File | Purpose |
|------|---------|
| `Owezy Mobile App-screens.html` | In-app screen mocks |
| `owezy-mobile-design-system.md` | Tokens, components, icon set, motion |
| `assets/` | App icons, splash, brand images |

If this folder is empty, `/spec-build` will proceed using stub screens and note the gap in the architecture doc's Open Questions section.
